Participant-level analysis data are intentionally excluded from this code-only archive.

For internal reruns, place the required final analysis files in this `data`
directory using the exact filenames referenced in each `.inp`.

Core final files used by the primary and new sensitivity analyses:
- Scenario_A_long_final.txt
- Scenario_B_long_final.txt
- Scenario_A_short_final_revised.txt
- Scenario_B_short_final_revised.txt

Some reconstructed S3/S4 reruns may additionally require the legacy-order files
described in the INTERNAL reproducibility archive.

A separate INTERNAL reproducibility archive contains the final anonymous
analysis files. Public participant-level data deposition remains subject to the
final Data Availability and ethics/data-sharing decision.
